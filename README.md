# Даня · Глава 24 — Birthday multiverse

Распакуй весь архив и открой `index.html`. Для сайта на хостинге загрузи всё содержимое папки `danya-anime-v2`, сохраняя папки и имена файлов. Сборка и установка пакетов не нужны. Картинки, стили и JavaScript находятся внутри сайта; внешних библиотек нет.

## Музыка

1. Положи несколько MP3 в `audio/music/`, например `01.mp3`, `02.mp3`, `03.mp3`.
2. Открой `config.js` и заполни `tracks`:

```js
tracks: [
  { title: 'Opening — твой первый трек', src: 'audio/music/01.mp3' },
  { title: 'Вторая арка', src: 'audio/music/02.mp3' },
  { title: 'Ending — финал', src: 'audio/music/03.mp3' },
],
```

Сайт пытается включить первый трек сразу. Если браузер блокирует звук, запуск повторяется при первом нажатии на страницу. Кнопки «Начать эпизод» и ▶ также включают музыку. Автозапуск со звуком без действия пользователя зависит от браузера. Чтобы отключить попытку автозапуска, поставь `autoplayMusic: false` в `config.js`. На конце трека включается следующий; после последнего плейлист идёт сначала. Пауза, следующий трек, громкость, перемотка и список треков доступны в плеере. ☰ открывает настройки.

Для быстрой проверки можно выбрать несколько аудиофайлов кнопкой «＋ Выбрать файлы» в плеере. Они используются только в текущем открытии страницы. Чтобы музыку услышал Даня, добавь её в папку сайта и `config.js`.

На iPhone система может управлять громкостью аудио через аппаратные кнопки вместо ползунка страницы. Проверяй итоговые уровни на устройстве, с которого Даня будет смотреть подарок.

## Озвучка

Подготовлены четыре поздравления от девушек и основное письмо от друга. Тексты в `VOICE_SCRIPT.md`.

Положи MP3 в `audio/voices/`, затем заполни `voices` в `config.js`:

```js
voices: {
  neon: 'audio/voices/neon.mp3',
  gothic: 'audio/voices/gothic.mp3',
  mirror: 'audio/voices/mirror.mp3',
  rose: 'audio/voices/rose.mp3',
  finale: 'audio/voices/finale.mp3',
},
```

Кнопки появляются только у подключённых озвучек. Одновременно играет один голос. Пока он звучит, музыка становится тише, затем возвращается к выбранной громкости. Пауза музыки сохраняется: конец озвучки не запускает её заново. Остановить голос можно у сцены или в настройках плеера.

В настройках плеера появляется опция «Озвучка сцен при прокрутке». По умолчанию она включена. Озвучка при прокрутке начинает работать после первого нажатия на страницу, которое разрешает звук. С включённой опцией сцена озвучивается один раз за открытие страницы, если достаточно видна и другой голос не играет. На телефонах ограничения браузера могут потребовать ручное нажатие кнопки сцены; ручные кнопки остаются доступными. Не кладите фоновую музыку внутрь самих голосовых файлов: плеер уже играет её отдельно.

## Дизайн и эффекты

Главный экран — Даня в мире «Нет игры — нет жизни». Дальше — настоящая история дружбы, интересы, четыре персональные сцены, словарь ваших реплик, кооператив, кадр после титров, прошлые поздравления, секретный подарок и финальное письмо.

Предметы из архива — изображения, а не GLB-модели. Объёмный эффект сделан через перспективу, наклоны, тени, движение слоёв при прокрутке и парение. Это сохраняет лёгкость страницы. Вращение не показывает обратную сторону предмета.

На компьютере карточки наклоняются за курсором; на телефоне эффекты работают от прокрутки и нажатий. Иллюстрации открываются целиком. Секретный подарок открывается нажатием. Финальная кнопка запускает конфетти. Движение можно отключить кнопкой ✦ в шапке; системная настройка уменьшенного движения также учитывается.

Шесть иллюстраций и шесть предметов преобразованы в WebP; суммарно около 784 КБ. У геймпада использован один фронтальный ракурс вместо листа из трёх ракурсов. Изображения ниже главного экрана загружаются лениво.

## Мобильная версия

Настроены компоновки для узких экранов, в том числе 320–430 px: одна колонка сцен, крупные кнопки, собственная компоновка главного экрана, скрытая нижняя метка главы, фиксированный компактный плеер, отступ для системной безопасной зоны. Нет зависимостей от наведения курсора. Мобильные стили работают и без JavaScript.

Проверь на своём телефоне перед отправкой: главную страницу, прокрутку до конца, увеличение изображений, воспроизведение музыки, смену трека, паузу и финальную кнопку. В среде создания проверены ссылки на файлы, структура HTML и логика интерфейса в симуляции DOM; полноценный браузерный прогон и реальное воспроизведение на iPhone/Android не выполнены, поскольку браузер недоступен.
